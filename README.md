# YouTube Clone

<!-- Brief project overview -->
A **responsive YouTube-like video streaming interface** built with **HTML, CSS, and Google Fonts**.  
This project mimics the layout of YouTube, including a **header**, **sidebar navigation**, and a **dynamic video grid** with responsive thumbnails.

---

## Features

<!-- List the key features -->
- **Responsive layout**: Works seamlessly across desktop, tablet, and mobile devices.  
- **Header**: Includes search bar, voice search, create button, notifications, and profile icon.  
- **Sidebar**: Navigation with icons and labels (Home, Explore, Subscriptions, Library, etc.)  
- **Video Grid**:  
  - Big video thumbnails (full-width / 1 column on desktop)  
  - Video title, author, and stats  
  - Responsive sizing for smaller screens  
- **Hover effects**:  
  - Header icons change opacity and cursor pointer  
  - Sidebar icons highlight on hover  

---

## Tech Stack

<!-- Technologies used in the project -->
- **HTML5** – Semantic structure  
- **CSS3** – Flexbox, Grid, and media queries for responsive design  
- **Google Fonts** – Roboto for typography  
- **Images** – PNG thumbnails and icons (YouTube-style)
